# Sprint_5 — UI-тестирование Stellar Burgers

## Описание проекта
Автотесты на Selenium для учебного сервиса Stellar Burgers.  
Проверяются функции регистрации, авторизации, переходов между страницами  
и разделами конструктора.

## Функциональность, покрытая тестами
- Регистрация нового пользователя
- Вход в систему через разные кнопки
- Переходы в личный кабинет и конструктор
- Навигация по разделам конструктора бургеров
- Выход из системы

## Как установить проект
1. Клонировать репозиторий:
```bash
git clone git@github.com:FoxuneQA/Sprint_5.git
```

2. Установить зависимости:
```bash
pip install selenium
```

## Как запустить тесты
```bash
pytest -v
